### 🧑‍💻 Sobre mim

Sou desenvolvedor full-stack com **aproximadamente 3 anos de experiência**,
construindo desde o banco de dados até a interface. Gosto de entender como as
coisas funcionam por dentro: em vez de só usar um API gateway, um editor
colaborativo ou uma plataforma de vídeo, eu construo um do zero para aprender
onde estão os problemas difíceis.

- 💼 Atualmente trabalho como desenvolvedor na [Optidata](https://work.optidata.com/)
- 🧠 Full-stack, do back-end em **PHP (Laravel)**, **Node (NestJS)** e **Go** ao front-end em **React + TypeScript**
- 🏗️ Interessado em **arquitetura de software**, **sistemas distribuídos**, **resiliência** e **observabilidade**
- 🤖 Explorando como colocar **IA** dentro de sistemas reais, com o humano no controle
- ✅ Testes, CI e código limpo não são opcionais: todo projeto meu tem pipeline, cobertura e regras de qualidade

### 🚀 Projetos em destaque

#### 🛡️ [pyle](https://github.com/MatheusZuchiBalbinot/pyle): API gateway distribuído

Um API gateway escrito do zero, com **data plane e control plane separados**.
Roteamento por prefixo, chaves de API guardadas só como hash, **rate limiting
distribuído** no Redis, balanceamento (round robin, menos conexões, aleatório
ponderado), **health checks, circuit breaker e retries**. A configuração chega a
todos os gateways em menos de um segundo, com troca atômica de snapshot. Um
console em React mostra tudo **ao vivo**, e um **assistente de IA** investiga
incidentes e propõe correções que o operador confirma. Tem benchmark contra o
nginx, injeção de falhas e mais de 1.700 testes.

`Node` `NestJS` `TypeScript` `React` `PostgreSQL` `Redis` `Prisma` `Docker` `Anthropic`

#### 🎬 [metube](https://github.com/MatheusZuchiBalbinot/metube): plataforma de vídeo full-stack

Uma plataforma de vídeo completa: **upload resumível** (tus), processamento
assíncrono com filas, **streaming adaptativo em HLS** gerado com ffmpeg,
recomendações no servidor, notificações em tempo real e um **pipeline de IA**
que transcreve (Whisper), gera capítulos e resume os vídeos, com um chat para
perguntar sobre o conteúdo. Observabilidade com OpenTelemetry.

`PHP` `Laravel` `Octane` `Horizon` `Reverb` `React` `TypeScript` `PostgreSQL` `Redis` `Whisper`

#### 📝 [palimpsesto](https://github.com/MatheusZuchiBalbinot/palimpsesto): editor colaborativo com E2EE

Um editor de texto colaborativo em tempo real baseado em **CRDT** (Yjs), com
**criptografia de ponta a ponta**: várias pessoas editam o mesmo documento ao
mesmo tempo, e o servidor é tecnicamente incapaz de ler uma linha do que
escrevem. Back-end em Go com WebSocket.

`Go` `WebSocket` `CRDT` `Yjs` `React` `TypeScript` `PostgreSQL` `Criptografia`

#### ⚡ [php-runtime-lab](https://github.com/MatheusZuchiBalbinot/php-runtime-lab): benchmark de runtimes PHP

Um laboratório para medir como diferentes modelos de execução do PHP se
comportam sob recursos limitados: **FPM, Swoole, RoadRunner, FrankenPHP e
Laravel Octane**, comparados com o mesmo orçamento de CPU e memória, carga
gerada com k6 e relatórios com checagem de confiabilidade.

`PHP` `Swoole` `RoadRunner` `FrankenPHP` `Laravel Octane` `k6` `Docker`
